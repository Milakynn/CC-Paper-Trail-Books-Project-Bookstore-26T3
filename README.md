# CC-Paper-Trail-Books-Project-Bookstore-26T3
This is an application for Paper Trail Books that will sell books online.

This application is a online bookstore for Paper Trail Books.
They decided to build an application to sell their books online because of the increasing competitions.
This application will serves as a inventory system, where they will be able to check their storage without having to go to the warehouse, they will be able to analysis their sales, the ingrowing custumer base, and how books sells better.
